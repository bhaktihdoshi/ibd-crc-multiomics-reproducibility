# sCCA Yachida Failure Audit

The previous 105/200 Yachida bootstrap failures were traced to zero-SD metabolite columns arising inside PMA tuning-fold training matrices. The full bootstrap matrices had zero-SD columns removed before PMA input, but the R helper originally passed unfiltered inner-fold training matrices to PMA::CCA, whose `typez="standard"` setting performs additional internal standardisation. The additive focused-validation helper now removes zero-SD columns within each PMA fit and maps excluded columns back to zero loading in the complete harmonised feature universe.

No participant identifiers are exported; bootstrap row multiplicities are reported only as anonymous count distributions.
