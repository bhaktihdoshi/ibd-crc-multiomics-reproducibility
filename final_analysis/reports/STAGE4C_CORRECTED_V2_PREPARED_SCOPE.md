## Blocking Criteria Before Full Stage 4C Execution

- Corrected-v2 metabolome and authoritative genus microbiome inputs must be present.
- MOFA must use cohort-local preprocessing: microbiome closure/zero handling/CLR/scaling and metabolome median imputation/scaling.
- Cohort-local metabolome scaling removes raw unit differences for structural analysis but does not establish absolute cross-cohort abundance transport.
- Pooled IBD-vs-control and CRC-vs-control labels must be used only for post-hoc annotation, not model fitting.
- CD/UC subtype phenotype tests must remain excluded from corrected-v2 Stage 4C.
- Clinical variables must not be included as MOFA/sCCA molecular views.
- sCCA must be independently fitted in each cohort; held-out canonical correlations and final-refit correlations must be reported separately.
- Cross-cohort sCCA component matching must use absolute loading similarity, sign alignment after matching, cosine similarity over the complete harmonised feature universe, and selected-feature Jaccard overlap.
- Optional 5/8/10-factor MOFA sensitivity and optional sCCA bootstrap stability are prepared but not executed by this script.
