## Blocking Criteria Before Full Stage 4E Execution

- Corrected-v2 Stage 4D graph modes must be available with node order matching corrected-v2 feature order.
- The primary GCN analysis is within-cohort topology evaluation, not cross-platform external deployment.
- Each cohort must compare identity, KEGG-only, and KEGG+NJC19 using identical architecture, seed, split, preprocessing, and participants; only adjacency changes in the strict topology ablation.
- A within-cohort early-integration ridge baseline must use the same participants and outer folds.
- Identity mode must use named node identities, not anonymous feature indices that can silently reorder.
- Splits and seeds must be identical across graph modes for topology ablation.
- Class weighting must be learned from training data only.
- Logits and probabilities must both be exported to diagnose compression or saturation.
- Any external GCN analysis is secondary as-supplied-scale stress testing and must not be described as fair calibrated external deployment or as failure of GCNs generally.
