# Results

Thesis-facing copies of final outputs, collected here for convenience. The authoritative source for every file here is `final_analysis/` (Stage 4) or `analyses/03_cross_cohort_replication/` (Stage 2/3) — if a number here ever looks inconsistent with those, the authoritative folder wins; report the discrepancy rather than trusting this copy.

- `final/figures/`, `final/tables/` — final thesis-facing figures and tables. Stage 4B uses the **post-freeze co-primary display** (`post_freeze_table2_stage4b_transportability_co_primary.csv`, `post_freeze_figure_B_stage4b_transportability_co_primary.png`), not the original frozen principal/stress-test-labelled versions (those remain in `final_analysis/` for provenance only — do not use them for the thesis).
- `final/supplementary/` — reserved for any additional supplementary thesis material.
- `sensitivity/` — post-freeze CRC microbiome representation sensitivity results (external performance, paired BH-FDR comparisons).
- `exploratory/` — reserved for any exploratory-analysis result the author wants surfaced here; empty by default, since exploratory results live in `exploratory/` with their own warnings.
