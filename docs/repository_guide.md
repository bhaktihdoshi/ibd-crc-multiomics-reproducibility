# Repository Guide

**New here? Read in this order:**

1. `README.md` — project overview, cohorts, repository structure.
2. `final_analysis/README.md` — where the final thesis numbers come from and how to verify them.
3. `docs/analysis_overview.md` — the full pipeline as a diagram, including the exploratory side-branch.
4. `docs/limitations.md` — what the analysis does and does not establish.
5. `docs/file_provenance_map.csv` — for any specific file, its original location, classification, and why it's here.

**Looking for a specific thing:**

| I want... | Go to |
|---|---|
| The final Stage 4 predictive/integration results | `final_analysis/` |
| The Stage 2/3 biological replication findings | `analyses/03_cross_cohort_replication/` |
| Thesis-facing figures/tables | `results/final/` |
| How preprocessing actually worked | `preprocessing/` |
| Sensitivity analyses | `results/sensitivity/`, `docs/sensitivity_analysis_guide.md` |
| Earlier/alternative approaches | `exploratory/` (read the warning in its README first) |
| How to reproduce a number | `docs/reproducibility.md` |
| Whether a file was reviewed for privacy/size/portability | `docs/file_provenance_map.csv`, `docs/privacy_security_audit.md`, `docs/large_file_audit.csv`, `docs/portability_audit.csv` |
| Data sources / how to obtain raw data | `data/README.md` |

See also `docs/analysis_file_classification.csv` for a per-file classification (`FINAL_AUTHORITATIVE`, `SENSITIVITY`, `HISTORICAL_SUPERSEDED`, etc.).
