# CRC Stage 2 Calibration Policy

CRC Stage 2 will follow the frozen IBD calibration policy.

The analysis will retain:

- Brier score
- calibration curve as external assessment only
- calibration intercept as external assessment only
- calibration slope as external assessment only

The analysis will not:

- recalibrate on the external cohort
- select models using calibration
- select thresholds using calibration
- claim clinical readiness from calibration outputs

Calibration estimates will be labelled exploratory when sample size or class variation is limited.
