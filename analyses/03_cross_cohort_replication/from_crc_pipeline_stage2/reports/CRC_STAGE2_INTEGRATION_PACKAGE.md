# CRC Integration Package for Future IBD-to-CRC Modelling

This package is a contract for later cross-disease latent-space work. It does
not implement the IBD-to-CRC trajectory model. The within-CRC analysis remains
CRC vs Control as the primary externally validated task, with Yachida-only stage
analyses treated as secondary/internal.

## Reporting-Completion Revision

The Stage 2 package now includes external ROC/PR curves with bootstrap CIs, nested-CV stability, transportability summaries, calibration assessment, probability distributions and predictive feature summaries. These are reporting-only additions; original predictions, thresholds, selected models and fitted joblibs are unchanged.
