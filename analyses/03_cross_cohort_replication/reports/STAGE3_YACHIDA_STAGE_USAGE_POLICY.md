# Stage 3 Yachida Stage Usage Policy

Yachida staging may be used only as an exploratory cross-sectional ordered disease-state variable:

Healthy -> MP -> Stage 0 -> I -> II -> III -> IV

HS is a post-surgical control group and must be excluded from ordered disease-state analyses.

This is not longitudinal evidence, not patient progression, and not evidence of transition probabilities. Stage ordering is used only for cross-sectional state comparison.
