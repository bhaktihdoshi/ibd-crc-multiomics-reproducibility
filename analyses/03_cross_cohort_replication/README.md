# Stage 3 — Cross-Cohort Biological Replication (IBD–CRC Integration)

This folder is the GitHub-repository copy of the thesis's **Stage 3 IBD–CRC integration workspace** (source: `thesis_preprocessing_workflow/stage3_ibd_crc_integration/`). It is the **cross-cohort biological replication analysis**: it takes the frozen, disease-specific metabolomics results from earlier stages (IBD final outputs; CRC Stage 2 frozen outputs) and asks whether the same metabolite signals replicate **within** disease across independent cohorts, and whether they are shared, disease-specific, or directionally concordant/discordant **across** IBD and CRC.

Stage 3 is explicitly part of the thesis's final scientific status and covers three sub-analyses:

- **Stage 3A** — within-disease concordance and cross-disease effect correlation across a strict four-cohort shared HMDB feature space (56 metabolites; 55 complete effect-profile rows in Stage 3A, since HMDB0000168 lacked an iHMP effect).
- **Stage 3B** — the Yachida cross-sectional ordered disease-state analysis (Healthy → MP → Stage 0–IV, excluding HS; 317 samples).
- **Stage 3C** — supporting validation/QC checks feeding the above.

The original workspace README is preserved as `README_STAGE3_original.md` in this folder for full context on what was and was not executed in this stage (e.g., PCA/UMAP, graph construction, and nested-CV modelling were explicitly **not** run here).

**Integrated interpretation** (from `reports/STAGE3_FINAL_RESULTS_SYNTHESIS.md`): the data support reproducible metabolomic effects *within* IBD, weak cross-cohort reproducibility *within* CRC, limited descriptive IBD–CRC directional overlap, and some cross-sectional CRC disease-state-associated metabolite trends — but they do **not** support a robust shared IBD–CRC biomarker signature.

### A note on the ambiguous "IBD replicated events" number

`tables/stage3_final_results_numbers.csv` contains one row where **"IBD replicated events" = 10**. This is the *sum* of IBD-vs-Control (7) and CD-vs-Control (3) strict replication events — it is **not** a count of 10 distinct IBD-vs-Control metabolites. A corrected/clarified copy exists at `tables/stage3_final_results_numbers_relabelled.csv` (produced by `scripts/relabel_stage3_final_results_numbers.py`) — **prefer that file** when citing this number. Both are kept for full audit trail.
